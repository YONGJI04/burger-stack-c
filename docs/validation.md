# 검증 기록

## v1.1.0 · 2026-11-04

- Linux/WSL: `make test`, `make sanitize` 통과. 터미널 시나리오 10개를 일반 빌드와 ASan/UBSan 빌드에서 실행했다.
- 터미널 시나리오: 정상·오답 서빙, 되돌리기, 한글 이름 편집·랭킹 저장, 저장 실패, 무입력 시간 종료, 창 크기 변경 시 시간 정지, 일시정지·복귀, 다음 주문을 시작한 뒤에도 성공 안내 유지, 96×32 컬러 화면에서 최대 12개 재료를 쌓고 80×24로 줄이기, 종료 시 터미널 설정 복구.
- `./build/test_game 20261104 100000`: 100,000개 모의 게임 통과. 자료구조·시간·랭킹·일시정지·그림 배열 경계 검사를 합쳐 4,191,825개 확인.
- Windows: 로컬 MinGW GCC로 빌드한 실행 파일을 Windows ConPTY에 연결했다. 실제 키 입력으로 메뉴 → 치즈버거 서빙 → 일시정지·복귀 → 한글 이름 `김셰프` 입력·수정 → 랭킹 파일 저장 → 정상 종료까지 통과했다.
- 그림은 게임의 `--demo` 실제 출력을 캡처해 96×32와 80×24 두 크기에서 확인했다.

자동 플레이는 조작과 상태 전이를 검증한다. 재미와 체감 난이도에 대한 여러 사람의 플레이 평가는 아직 받지 않았다. macOS에서 직접 실행하지는 않았다.

## v1.0.0 기반 10시간 반복 검증

개선 작업은 별도 작업 트리에서 진행하여 기존 검증의 소스를 바꾸지 않았다.

- 소스 기준: `cb1ff80` (게임 구현 `cf476c8`과 동일, CI 패키지 경로만 변경).
- 실제 실행시간: 단조 시계 기준 36,000초.
- 반복: 600회, 매회 다른 시드로 10,000게임.
- 합계: **6,000,000게임, 실패 0건**, 최종 상태 `completed`.
- 원본 상태·상세 로그는 로컬 `logs/soak-status.json`, `logs/soak.log`에 있다.

이 10시간 기록은 v1.0.0 게임 로직의 검증이다. v1.1.0의 변경 사항은 위 별도 검증 결과를 따른다.
